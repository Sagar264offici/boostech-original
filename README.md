# boostech website source

This is the React + Vite source project for the boostech marketing website.

## Stack
- React 18 + Vite
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- Framer Motion
- React Router
- Lucide React icons

## Run locally

Install Node.js 20+ (Node.js 22 recommended), then:

```bash
npm install
npm run dev
```

Vite will print the local development URL.

## Production build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`.

## Deploy to Vercel

Import this folder as a Vercel project or run:

```bash
npx vercel
```

The included `vercel.json` rewrites the app routes to the Vite entry point.
